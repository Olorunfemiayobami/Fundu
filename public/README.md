# Fundu icons: Help and support

Icons used on the Help page, search with no results, the contact form states, the topic pages and the article pages.

Outline icons on a 24 × 24 grid, stroke width 2, round caps and joins, drawn in `currentColor` so they take the text colour. Recommended: use the matching `lucide-react` icon by the name below (`npm install lucide-react`). Use `size={20}` in topic chips and search, 16 to 18 in buttons and rows, `strokeWidth={2}`.

| File | Used for | Lucide name |
|---|---|---|
| `alert.svg` | Contact form errors | `triangle-alert` |
| `back.svg` | “All … articles” button on article pages | `arrow-left` |
| `bank.svg` | Bank transfers topic | `landmark` |
| `bulb.svg` | Tip boxes in articles | `lightbulb` |
| `ccircle.svg` | “Message sent” confirmation | `circle-check` |
| `chev.svg` | FAQ rows (expand) and topic dropdown on mobile | `chevron-down` |
| `chevr.svg` | Topic cards on mobile, article rows, related articles | `chevron-right` |
| `clock.svg` | Reading time | `clock` |
| `folder.svg` | Managing campaigns topic | `folder` |
| `info.svg` | Note boxes in articles | `info` |
| `plus.svg` | Creating a campaign topic | `plus` |
| `search.svg` | Help search | `search` |
| `share.svg` | Sharing and visibility topic | `share-2` |
| `user.svg` | Account and privacy topic | `user` |

Topic chips use a 40px (Help page) or 56px (topic page) rounded square in pale teal `#E3F1F0` with the icon in `#16615F`. Tip boxes use the lightbulb in dark orange `#9A4A06`.
